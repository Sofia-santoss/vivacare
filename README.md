# VivaCare

Sistema de gestão da experiência do paciente e de indicadores de atendimento hospitalar.

Hospital de referência: Fundação Hospitalar Dr. Oswaldo Diesel.

> Projeto em desenvolvimento. Ainda não está pronto para produção.

## Objetivo

Substituir as pesquisas de satisfação em papel por uma pesquisa digital simples para pacientes, permitindo analisar indicadores de atendimento (como o NPS), identificar oportunidades de melhoria e acompanhar manifestações de Ouvidoria.

## Tecnologias

- Frontend: React, TypeScript, Vite e Tailwind CSS
- Backend: Node.js, TypeScript e Express
- Banco de dados: PostgreSQL

## Estrutura planejada

```
vivacare/
├── frontend/   interface do paciente e painel de gestão
├── backend/    API
├── database/   migrations
├── docs/       documentação e registro de tarefas
└── tests/      testes
```

As pastas serão criadas aos poucos, conforme o desenvolvimento avança.
